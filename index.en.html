BLACKOUT GUARD

Blackout Guard & Startup Delay

Instantly detects power outages, models chamber warming (+1.4°C/h freezer, +0.8°C/h fridge), and enforces a mandatory 5-minute restart delay to prevent compressor liquid slugging.

⚖️
XX:05 RECONCILE

Hardware Calibration & Anti-Stall

Continuous hourly calibration at XX:05 against the plug's dedicated metering chip (add_ele). Socket Anti-Stall prevents frozen hardware registers under steady compressor loads.

Quick Start

Deployment on Android / Linux

Deploy the complete server in minutes inside Termux on an Android TV Box, Raspberry Pi, or any Linux/Windows PC.

1. Clone Repository & Install Dependencies:

git clone https://github.com/ALEVOLDON/SmartFridge-Telemetry-Kiosk.git
cd SmartFridge-Telemetry-Kiosk
pip install -r requirements.txt
cp config.example.json config.json

2. Launch Telemetry Server:

# Standard foreground server launch:
python auto_monitor.py

# Or 24/7 background daemon in Termux:
bash scripts/h96_start_fridge.sh

The web dashboard will automatically be available at port 8088: http://<SERVER_IP>:8088/ (for vintage iPad tablet: /ipad).
