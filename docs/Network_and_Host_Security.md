# 🛡️ ПЛАН ПРОВЕРКИ И УСИЛЕНИЯ БЕЗОПАСНОСТИ СЕТИ НА ЗАВТРА

**Дата создания:** 27.08.2026  
**Цель:** Обеспечить 100% защиту домашнего Wi-Fi роутера, компьютеров и микросервера H96 Max от взлома и внешнего сканирования.

---

## 1. 📡 Аудит и настройка домашнего роутера (Первый рубеж защиты)

### 🔹 Шаг 1.1: Смена заводского пароля администратора
- [ ] Зайти в панель управления роутером (обычно `http://192.168.0.1` или `http://192.168.1.1`).
- [ ] Убедиться, что пароль для входа в веб-интерфейс изменен со стандартного (`admin / admin` или `admin / 1234`) на надежный уникальный пароль.

### 🔹 Шаг 1.2: Отключение опасных автоматических протоколов
- [ ] **Отключить UPnP (Universal Plug and Play):**
  * *Почему:* Вредоносные программы могут использовать UPnP, чтобы автоматически без вашего ведома открывать порты наружу в интернет.
- [ ] **Отключить WPS (Wi-Fi Protected Setup):**
  * *Почему:* Функция подключения по PIN-коду/кнопке уязвима к быстрому перебору (Pixie Dust / Reaver атаки).

### 🔹 Шаг 1.3: Проверка открытых портов (Port Forwarding / DMZ)
- [ ] Проверить раздел **Port Forwarding (Проброс портов)** и **Virtual Server**:
  * Убедиться, что порты `5555` (ADB), `8022` (SSH), `8080` (Bot Dashboard) и `8088` (Монитор) **НЕ проброшены в интернет**.
- [ ] Проверить раздел **DMZ (Демилитаризованная зона)**:
  * Убедиться, что DMZ отключен (или в нем не указан IP приставки `192.168.0.102`).

### 🔹 Шаг 1.4: Безопасность Wi-Fi сети
- [ ] Убедиться, что режим защиты Wi-Fi установлен в **WPA2-PSK (AES)** или **WPA3-SAE**.
- [ ] Отключить устаревший и взламываемый алгоритм **TKIP** и **WEP**.

### 🔹 Шаг 1.5: Удаленное управление роутером (Remote Management / WAN Access)
- [ ] Убедиться, что пункт *«Доступ к панели роутера из внешней сети (WAN)»* **ОТКЛЮЧЕН**.

---

## 2. 🤖 Безопасность микросервера H96 Max (Termux / Android)

### 🔹 Шаг 2.1: Пароль и доступ к Termux
- [ ] Задать надежный пароль в Termux командой: `passwd`

### 🔹 Шаг 2.2: Настройка авторизации по SSH-ключам (Public Key Authentication)
- [ ] Сгенерировать современный стойкий SSH-ключ на ПК (`ed25519`).
- [ ] Скопировать публичный ключ на приставку, чтобы подключаться с ПК без ввода пароля в открытом виде.
- [ ] Отключить вход по паролю в конфиге `sshd_config` (оставить только вход по ключам).

### 🔹 Шаг 2.3: Сетевой ADB
- [ ] Использовать ADB только при активной работе с ПК, либо защитить порт 5555 встроенным файрволом (`iptables`).

## 3. 🏠 Дополнительно: Изоляция устройств умного дома (IoT)
- [ ] По желанию: настроить **Гостевую Wi-Fi сеть** на роутере для китайских умных розеток/лампочек, чтобы они были изолированы от вашего основного ПК и личных файлов.
