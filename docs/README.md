## 🧊 Краткая сводка: Паспорт холодильника Samsung RT34MB

```text
Модель агрегата:        Samsung RT34MB (RT34MBTS)
Класс:                  Top Mount Freezer (276 л / 9.8 cu.ft)
Схема проводки:         DA68-01441A (электромеханический No-Frost)
Модель компрессора:     Samsung SK170K-T1U TS1 (Корея)
Питание:                200–220 В ~ 50 Гц (1 фаза, LRA: 5.8 А)
Хладагент (фреон):      R-134a, норма заправки строго 160 грамм
Электрическая мощность: 110–135 Вт (мотор) / ~160 Вт (ТЭН оттайки)
Холодопроизводительность: ~160 Вт при -23.3°C
Термостат:              Pacific Controls PFN-C174S-03EB-1 (Samsung DA47-10107)
Нормативный КРВ:        0.30 – 0.45 (Эталонный рабочий баланс: ~0.39)
```

## ⏱️ Нормативы рабочих циклов

| Режим | Мощность (Вт) | Норма времени | Физический процесс |
| :--- | :---: | :---: | :--- |
| 🟢 **Охлаждение** | `115 – 140 Вт` | $20 \dots 35\text{ мин}$ | Компрессор SK170K и вентилятор обдува испарителя нагнетают холод |
| ⚪ **Отдых** | `0.0 Вт` | $35 \dots 55\text{ мин}$ | Термостат разомкнут. Теплоизоляция удерживает мороз в камерах |
| 🔥 **Оттайка No-Frost**| `150 – 165 Вт` | $20 \dots 28\text{ мин}$ | Механический таймер подключает ТЭН испарителя для таяния инея |
| 💧 **Пауза каплепадения**| `0.0 Вт` | $7 \dots 12\text{ мин}$ | Дренаж талой воды перед повторным пуском мотора |
