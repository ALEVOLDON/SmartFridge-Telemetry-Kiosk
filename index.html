Возможности комплекса

Инженерные решения для полного контроля

Комплекс непрерывно анализирует электрические параметры, предсказывает термодинамику и оперативно защищает агрегат при любых авариях в электросети.

⚡

100% Локальный LAN-режим

Прямой опрос розетки Tuya по протоколу TinyTuya v3.5 через домашний Wi-Fi (порт 6668). Пинг опроса составляет всего ~10 мс, а платные лимиты Tuya Cloud расходуются на 0%.

🧊

Предиктивная термомодель

Математическая теплофизическая модель оценивает температуру морозильной (-19°C) и холодильной (+4°C) камер в реальном времени на основе теплоемкости и теплопотерь — без сверления стенок и установки внешних датчиков.

🛡️

Контроль блэкаутов & Пауза пуска

Мгновенное обнаружение отключений 220В с фиксацией длительности и расчетом тепловой безопасности продуктов. Автоматическая 5-минутная блокировка пуска защищает компрессор от пуска под высоким давлением фреона.

🔥

Диагностика No-Frost оттайки

Автоматическая детекция работы ТЭНа оттайки (~155 Вт), хронометраж интервалов (9–12 ч) и предупреждение об обмерзании испарителя, отказе термодатчиков или микроутечке хладагента R-134a.

Развёртывание на Android / Linux

Система разворачивается за 2 минуты в среде Termux на любой Android-приставке или одноплатнике Raspberry Pi.

1. Клонирование и установка зависимостей:

git clone https://github.com/ALEVOLDON/SmartFridge-Telemetry-Kiosk.git
cd SmartFridge-Telemetry-Kiosk
pip install -r requirements.txt

2. Запуск фонового супервизора:

bash start_fridge.sh

Веб-интерфейс автоматически запустится на порту 8088. Откройте в браузере: http://<IP_ПРИСТАВКИ>:8088/.
