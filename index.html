Возможности комплекса

Инженерные решения для полного контроля

Комплекс непрерывно анализирует электрические параметры, рассчитывает термодинамику и защищает компрессор при любых сбоях сети.

⚡

100% Локальный LAN-режим

Прямой опрос розетки Tuya по протоколу TinyTuya LAN UDP/TCP каждые 3 секунды с пингом ~10 мс. 100% экономия облачных квот с автоматическим резервным переходом на Cloud OpenAPI при сбоях Wi-Fi.

🧠

Двухуровневый AI-копилот

Система 1 (TypeSafe AI Jev) обеспечивает мгновенную обработку команд (~80 мс) и расчет износа. Система 2 (Google Gemini Flash) консультирует по термодинамике и хранению продуктов с каскадом из 5 моделей.

🛡️

Контроль блэкаутов и Пауза пуска

Мгновенное обнаружение аварий 220В, расчет прогрева камер во время отключения (+1.4°C/ч в морозилке, +0.8°C/ч в холодильном отделении) и обязательная 5-минутная задержка пуска против гидроудара.

⚖️

Аппаратная калибровка & Anti-Stall

Непрерывная автоподстройка телеметрии через ежечасную сверку в XX:05 с аппаратным чипом розетки (add_ele). Защита сокетов Anti-Stall исключает зависание счетчиков при стабильной нагрузке.

🔥

Диагностика No-Frost оттайки

Автоматическая детекция работы ТЭНа оттайки (~155–165 Вт), хронометраж интервалов (9–14 ч) и предупреждение об обмерзании испарителя, отказе термодатчиков или микроутечке хладагента R-134a.

Киоск для старых iPad (iOS 8–12)

Специализированный Kiosk-интерфейс на чистом ES5 и CSS3. Идеально работает на винтажных планшетах (iPad 2/3/4) на кухонной дверце холодильника без зависаний и лишнего расхода батареи.

Развёртывание на Android / Linux

Система разворачивается за считанные минуты в среде Termux на ТВ-приставке или на любом ПК с Linux / Windows.

1. Клонирование репозитория и установка зависимостей:

git clone https://github.com/ALEVOLDON/SmartFridge-Telemetry-Kiosk.git
cd SmartFridge-Telemetry-Kiosk
pip install -r requirements.txt
cp config.example.json config.json

2. Запуск сервера мониторинга:

# Обычный запуск сервера:
python auto_monitor.py

# Или запуск службы демона 24/7 в Termux:
bash scripts/h96_start_fridge.sh

Веб-интерфейс автоматически доступен на порту 8088. Откройте в браузере: http://<IP_СЕРВЕРА>:8088/ (для планшета: /ipad).
